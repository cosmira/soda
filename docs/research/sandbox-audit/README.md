# Ручной аудит Sandbox

Проверены **все 173 входных замечания** стандартного набора правил на 37 PHP-файлах
`src`. Найден и исправлен **1 false positive**. В повторном отчёте остаётся
**169 подтверждённых нарушений политики; неразобранных сообщений нет**.
Ещё три сообщения сняты после пересмотра политики clone: два прямых запрета
и условие `(clone $missing)->exists()`. Это изменение стандарта, не дополнительные FP.
Исходники Sandbox не менялись. Граница вывода — зафиксированные исходники,
зависимость и конфигурация, а не любая будущая версия проекта.

## Исправленное срабатывание

`SandboxBelongsToMany::__construct` принимает восемь параметров и в том же порядке
передаёт их в `BelongsToMany::__construct`. Родительская сигнатура Laravel 13.18.1
проверена в исходнике `Illuminate/Database/Eloquent/Relations/BelongsToMany.php:160`.
Два promoted readonly-свойства сохраняют ссылки, не добавляя позиций входного API.

`MaxArguments` теперь сохраняет такую прозрачную передачу конструктору родителя.
Проверяется реальное наследование, известная сигнатура и единственный прямой вызов
`parent::__construct` со всеми неизменёнными позиционными параметрами. Совпадения
имён классов недостаточно. Конкретные конструкторы по-прежнему не становятся
обязательными PHP-контрактами для других правил, например поиска unused-параметров.

Регрессии проверяют также обратный порядок исходников, собственный конструктор,
отсутствующую зависимость, лишний аргумент, перестановку значений, другую арность
родителя и дополнительное поведение. Эти примеры остаются нарушениями лимита.

## Как проверялся остаток

- Строки и имена пересчитаны по исходнику, включая отступы, комментарии и отдельные
  вхождения переменных. Несколько сообщений о `$i` не означают несколько ошибок поведения.
- Для порядка методов сверены вызывающий метод, первое упоминание каждой цели
  и строки объявлений. Это политика порядка чтения, а не исполнения ветвей.
- Для синтаксических запретов проверены конкретные выражения: `else`, `[0]`,
  `app(...)`, `method_exists(...)`, `new $class`, static-свойства.
- Для длинных сигнатур перечислены параметры и проверено происхождение контракта.
  Для readonly-конструктора SandboxTable имеется локальный непродвигаемый параметр;
  исключение для полностью public promoted-конструктора к нему не относится.
- Булевы параметры прослежены до выбора force-захвата или активных/черновых таблиц.
  Требования к префиксам `supportsSandboxSync` и `missingKeyValues` — точная стилевая политика.
- Сложность конструктора SandboxTable проверена независимо: 1 + 5 if + 1 foreach
  + 7 логических операторов = 14.
- Для coupling перечислены реальные ссылки на 19, 12 и 18 различных типов.
  Неиспользуемые `use` сами по себе не считались зависимостью.
- Цикл namespaces подтверждён достижимостью каждой из девяти групп из каждой другой.
  Свидетели содержат классы, файлы и строки. Это не утверждение о цикле каждого класса
  или о том, что любое такое разделение namespaces является плохой архитектурой.

## Воспроизведение

```sh
SODA_SANDBOX_ROOT=/path/to/sandbox php vendor/bin/phpunit --filter SandboxAuditCorpusTest
```

Тест проверяет полный список файлов, хеши и мультимножество всех полей диагностик.
Без указанного checkout явно пропускается только интеграционная часть; целостность
реестра и автономные регрессионные примеры выполняются в обычном CI.

Полный запуск для Sandbox и ранее проверенных Laravel-пакетов:

```sh
SODA_SANDBOX_ROOT=/path/to/sandbox SODA_LARAVEL_CORPUS=/path/to/roots.json \
  php vendor/bin/phpunit --exclude-group performance --fail-on-deprecation
```

`FAIL` в Soda ожидаем: явные ограничения стандарта остаются нарушенными.
Нулевое число найденных false positive не означает нулевое число замечаний.
