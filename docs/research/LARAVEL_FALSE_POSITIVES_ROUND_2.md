## Исправленные причины

1. **Позиционные callback.** Pail `ProcessFactory.php:26` и Sail
   `Console/Concerns/InteractsWithDockerComposeServices.php:329`: первый аргумент
   `$type` сохраняет позицию второго, используемого аргумента. Для замыканий и
   стрелочных функций правило сохраняет позиции до последнего используемого входа.
   Неиспользуемые хвостовые входы и обычные именованные функции проверяются.
2. **Чтение результата принято за команду.** Pail `Handler.php:104` и Sail
   `InteractsWithDockerComposeServices.php:129`: результаты `id()` и `option()`
   используются как значения. Тернарное выражение, результат которого потребляется,
   больше не доказывает команду. Самостоятельное выражение с отброшенным результатом
   остаётся кандидатом. Побочные эффекты возвращающих значение методов требуют
   отдельного анализа; их отсутствие этим изменением не доказывается.
3. **Объект управляет собой.** Pail `File.php:66`, Sail `InstallCommand.php:57`,
   Serializable Closure `Serializers/Native.php:292,524`: обращения к `$this`,
   `self` и `static` находятся внутри владельца поведения. Это не вынесенное наружу
   решение о состоянии чужого объекта. Обращения к `$this->collaborator` проверяются.
4. **Документация принята за отключённый код.** Serializable Closure
   `Support/ReflectionClosure.php:750`: поясняющий текст с inline-примером
   `` `$obj->method(...)` ``. Inline-фрагменты Markdown исключаются из оценки;
   синтаксис отключённого кода вне них продолжает обнаруживаться.
5. **Нативный протокол потоков.** Serializable Closure `Support/ClosureStream.php`:
   восемь неиспользуемых позиций и лимит четырёх аргументов `stream_open` обусловлены
   внешним протоколом PHP. Soda распознаёт регистрацию своего `__CLASS__` через
   `stream_wrapper_register()` и сохраняет документированные позиции трёх hooks:
   `stream_open` (4), `stream_set_option` (3), `url_stat` (2). Дополнительные позиции
   проверяются. Одноимённые методы незарегистрированного класса не освобождаются.

Документированные сигнатуры PHP:
[stream_open](https://www.php.net/manual/en/streamwrapper.stream-open.php),
[stream_set_option](https://www.php.net/manual/en/streamwrapper.stream-set-option.php),
[url_stat](https://www.php.net/manual/en/streamwrapper.url-stat.php).

## Что остаётся ограничением

- Распознавание регистрации потоков пока локальное: собственный `__CLASS__` в
  объявляющем классе, три перечисленных hook. Регистрация через переменные,
  другой файл и другие нативные протоколы этим исправлением не покрываются.
- Нетипизированные параметры, запреты reflection, clone, динамических свойств,
  файловых операций, ограничения размера — выбранные требования политики.
  Наличие в Laravel не делает их срабатывание ложным автоматически.
- Интерфейсы без явных потребителей внутри пакета могут иметь внешних клиентов.
  Область анализа ограничена `src`; ненужность публичного API глобально не доказана.
- Остаточные 550 сообщений не объявляются доказанными дефектами PHP-программ.
  Для утверждения «0 false positive во всём отчёте» нужна полная индивидуальная
  классификация этих сообщений и согласованная политика для публичных библиотек.
  Ноль воспроизведённых ошибок в добавленных регрессионных случаях — проверяемый
  результат, но не гарантия для произвольного кода.
